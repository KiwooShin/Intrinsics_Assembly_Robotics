Papers driving decisions

ResearchPlan §1 — evidence → decision. Every technical call is traceable to a source.
arXiv:2602.22100
Connector-insertion BC scaling
CNN encoders beat transformer backbones 7–8×; val L1 does not predict success → scale demos 16→150+, select by scored rollouts.
arXiv:2410.18647
Diversity > count (ICLR'25 oral)
Generalization scales with config diversity, not demos per config → stratified collection, ≤1–2 demos per exact cell.
arXiv:2507.09061 · DART
Chunking + noise injection
Action chunking with noise-injected collection provably kills compounding error — oracle relabeling is free.
arXiv:2509.18644
Proprioception shortcut
Proprio state becomes a shortcut that kills spatial generalization → train with 50–80% TCP-pose dropout (needs relative actions).
arXiv:2409.11925 · Haptic-ACT
Force/torque token
F/T input lifts contact-phase success (80% vs 50% vision-only) → record + feed wrench; pipeline was dropping it.
arXiv:2304.13705 · ACT
Chunk multimodality + shift-aug
Far-future chunk error is a multimodality symptom; random pixel-shift is near-mandatory (73%→27% without) → CVAE/VQ head A/B.
arXiv:2506.05165 · LiPo
Chunk-boundary smoothing
Boundary jerk/stalls leak smoothness + duration points; LiPo blends without retraining → wrap deployment.
arXiv:2407.16677 · 2412.09858
Residual RL → re-distill (ResiP / RLDG)
Residual RL on frozen chunked BC: 5%→99% on tight pegs; engine sub-scores are a ready shaped reward → Stage-2.
arXiv:2108.13264 · rliable
Matched-seed evaluation
Paired matched-seed eval + IQM + bootstrap CIs separates policies at small n → fixed 50-config suite, same seeds.
